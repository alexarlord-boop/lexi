# Λέξεις — минимальный PWA

## Что внутри
- `index.html` — UI, добавление слов, карточка «тап → перевод», строка статуса PWA
- `manifest.webmanifest` — имя, иконки, `display: standalone` (без адресной строки)
- `sw.js` — service worker: кэш оболочки, работа офлайн
- `icons/` — иконки 180 (iOS), 192, 512

## Запуск локально
```bash
cd lexi-pwa
npx serve .        # или: python3 -m http.server 8000
```
Service worker работает только на `localhost` или по HTTPS.

## На iPhone (через GitHub Pages)
1. Создай репозиторий, залей содержимое папки.
2. Settings → Pages → Deploy from branch → `main` / root.
3. На iPhone открой `https://<user>.github.io/<repo>/` **в Safari**.
4. «Поделиться» → «На экран „Домой“».
5. Запусти с иконки — в статусе будет «📱 установлено». Включи авиарежим и проверь, что всё открывается.

## Обновление
Поменяй `VERSION` в `sw.js`, запушь, перезапусти приложение на телефоне (иногда дважды).

## Важно про данные
Данные живут только на телефоне и привязаны к установленной иконке.
Если удалить приложение с экрана «Домой», слова пропадут. Поэтому следующим шагом стоит сделать экспорт и импорт в JSON.
